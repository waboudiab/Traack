# Traack phases

Public name is Traack. The code package stays `quotedesk`.

## Phase 1 — Own inbox is allowed

The connected shop address is on the allow list. Mail you send to that same inbox can become a lead and runs the same ack, status, and Maps-link path as any other customer.

A lead still needs a lead word such as “quote” in the subject. Mail Traack itself sends is ignored: the ack, the Maps link, and the owner alert. Those notes do not create another lead.

## Phase 2 — Name and royal theme

Visible “Quote Desk” labels become Traack, including the install name and owner-alert subject. The screen uses royal purple for actions, gold for the brand line, and an ivory background. Hot, done, and declined colors stay separate from that purple.

## Phase 3 — Installable phone app

Home-screen icons, an Apple touch icon, safe areas, and an install hint. Android can use Install. iPhone uses Safari, Share, then Add to Home Screen.

The phone cannot install the app from `localhost` on the computer. A secure address (a tunnel or a Vercel deploy) is still required before the phone install can be finished.
